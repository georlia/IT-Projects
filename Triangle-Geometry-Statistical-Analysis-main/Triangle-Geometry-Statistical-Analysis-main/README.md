# 📐Triangle Geometry and Statistical Analysis
Δημιουργία τυχαίων σημείων σε καρτεσιανό επίπεδο, εντοπισμός έγκυρων τριγώνων και στατιστική ανάλυση των εμβαδών τους.

Περιγραφή Έργου
----
Το project επικεντρώνεται στη δημιουργία και ανάλυση γεωμετρικών σχημάτων σε ένα καρτεσιανό επίπεδο. 
* Δημιουργία **100 τυχαίων σημείων** με συντεταγμένες x και y από -100 έως 100.
* Εντοπισμός όλων των πιθανών συνδυασμών τριών σημείων που σχηματίζουν **έγκυρα τρίγωνα**.
* Υπολογισμός εμβαδών και εκτέλεση **στατιστικής ανάλυσης** (μέση τιμή, διάμεσος, τυπική απόκλιση).

Μαθηματικοί Τύποι
----
Για την υλοποίηση χρησιμοποιήθηκαν οι εξής τύποι:

### 1. Απόσταση μεταξύ δύο σημείων
$d = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$

### 2. Τύπος του Ήρωνα (Εμβαδό Τριγώνου)
Το εμβαδό $A$ υπολογίζεται από τον τύπο:
$A = \sqrt{s(s-a)(s-b)(s-c)}$

Όπου $s$ είναι η ημιπερίμετρος:
$s = \frac{a+b+c}{2}$

Δομή Αρχείων
---
* [utils.py](utils.py): Module με τις βασικές συναρτήσεις υπολογισμού απόστασης, εμβαδού και στατιστικών μεγεθών.

* [erotima_2.py](erotima_2.py): Περιλαμβάνει τα **Unit Tests** για την επαλήθευση της ορθότητας του κώδικα βάσει προκαθορισμένων τιμών.
* [points.txt](points.txt): Αρχείο δεδομένων με συντεταγμένες σημείων για τον έλεγχο των δοκιμών.
