# 📟Λειτουργικά Συστήματα

Προσομοιωτής QEMU1
---
1. Για να ξεκινήσετε το qemu χρησιμοποιήστε τη συντόμευση για το αρχείο start.bat στην επιφάνεια εργασίας. 
2. Στο σύστημα υπάρχουν δύο λογαριασμοί χρηστών, οι tele1 και tele2.
3. Μόλις σας ζητηθεί να κάνετε login θα πρέπει να δώσετε το username και το password του λογαριασμού στον οποίο θέλετε να συνδεθείτε.
4. Εισάγεται ως username: tele1 και ως password: tele1 (θυμηθείτε ότι όταν πληκτρολογείτε το password δεν εμφανίζεται τίποτα στην οθόνη).
5. Αφού συνδεθείτε επιτυχώς στο σύστημα, μπορείτε πλέον να δώσετε εντολέςώστε να υλοποιήσετε τα ερωτήματα της άσκησης.

Βοηθητικά Στοιχεία
---
* Πριν ξεκινήστε με τα ερωτήματα της άσκησης, καθαρίστε τα περιεχόμενα του λογαριασμού πληκτρολογώντας την εντολή `rm –r *`
* Για να δείτε τα περιεχόμενα ενός καταλόγου υπάρχει η εντολή `ls<κατάλογος>`, όπου <κατάλογος> είναι το όνομα διαδρομής του καταλόγου του οποίου θέλετε να δείτε τα περιεχόμενα. Η εντολή θα σας χρησιμεύσει για να ελέγχετε αν δημιουργήσατε σωστά τους καταλόγους των ερωτημάτων.

Νέες οδηγίες χρήσης του εξομοιωτή JSLinux 
---
1. Λήψη αρχείου jslinux.txt
2. Συνδεθείτε με τον εξομοιωτή JSLINUX: `https://bellard.org/jslinux/vm.html?url=alpine-x86.cfg&mem=192`
3. Εκτέλεση του αρχείου jslinux.txt 
Στην σελίδα του εξομοιωτή πατήστε το κουμπί με το βέλος στο κάτω μέρος της οθόνης.Επιλέξτε το αρχείο που κατεβάσατε στο πρώτο βήμα και φορτώστε το.Επιβεβαιώστε ότι το αρχείο μεταφέρθηκε στην εικονική μηχανή εκτελώντας την εντολή `ls` Εκτελέστε την εντολή:`source jslinux.txt` Αφήστε λίγο χρόνο να εκτελεστεί μέχρι να δείτε την προτροπή του κελύφους.
4. Συνδεθείτε σαν ο χρήστης tele1 Εκτελέστε την εντολή :`su -l tele1`
5. Συνεχίστε με την διαδικασία της άσκησης.
